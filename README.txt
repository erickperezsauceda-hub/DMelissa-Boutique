D'Melissa Boutique — V3 base oficial + Administrador de precios

Esta versión conserva la estética aprobada de la V3 e incorpora un área privada para administrar los precios del catálogo.

Administrador:
- Acceso desde el enlace “Administrador” del pie de página.
- Usuario de administrador: Dirian
Contraseña inicial: Melisau.26
- Permite agregar/editar el precio de los 25 productos.
- Los cambios se guardan automáticamente en el navegador mediante localStorage al presionar “Guardar precios”.
- Permite dejar un producto como “Consultar”.
- Incluye exportación e importación de precios en formato JSON.
- Incluye opción para restablecer todos los precios a “Consultar”.

Importante:
Esta implementación es adecuada para una tienda estática/local. La contraseña y los datos se gestionan en el navegador, por lo que NO debe considerarse un sistema de seguridad para producción. Para publicar una tienda con administración real y segura se recomienda conectar el panel a una base de datos y autenticación en servidor.

Características existentes:
- Búsqueda de productos.
- Filtros por categoría.
- Orden A-Z.
- Carrito local.
- Consulta de pedido por WhatsApp.
- Diseño responsive para computadora y celular.
